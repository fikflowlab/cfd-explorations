# CFD Exploration 001
## Water Wave Propagation

2D shallow-water wave propagation simulated using Basilisk C.

### Simulation
- Model: Saint-Venant equations
- Maximum refinement level: 7
- Adaptive Mesh Refinement (AMR)
- Simulation time: 0–2.5
- Output: 65 snapshots
